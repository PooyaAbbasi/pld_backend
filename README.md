##### How to Run?
you can run this project by installing requirements.txt and run it locally or
###### run with docker
To run this project with docker you can run `docker-compose.yml` file to run the development image
(images of this app are public in [pabbasi/pld_backend](https://hub.docker.com/repositories/pabbasi) on `Dockerhub`)
endpoints will be available on `localhost:8000`.
